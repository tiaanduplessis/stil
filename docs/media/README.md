# README media

These are captures of the native Android app on an Android 16 emulator, taken on 25 October 2026. No HTML mockup or generated phone UI is used.

- `home.png`: Serif home with five apps and a dimmed photo.
- `apps.png`: a name search for Clock in Light appearance. This emulator uses a hardware keyboard.
- `settings.png`: Dark appearance selected; the saved setting remains compatible with existing installs.
- `walkthrough.mp4`: a short H.264 recording of Settings → Font → Serif → Preview home → All apps → Clock search. Motion runs at normal speed; trailing idle time was removed.
The README embeds the video through GitHub's hosted player. The MP4 is also kept here for local playback and as a portable fallback. Access to the hosted attachment follows GitHub's repository permissions. Recheck playback after a fork or visibility change.

The home background is [James Forbes's forest photo](https://unsplash.com/photos/jrzvClypPq8), downloaded through Lorem Picsum (photo 190). It retains the [Unsplash License](https://unsplash.com/license), separate from the project's MIT license. The app's offline fallback and prototype sample credits are listed in [third-party notices](../../THIRD_PARTY_NOTICES.md).

Refresh these assets after visible UI changes. Use a dedicated emulator without personal data and capture at least home, app search, and settings. Keep text alternatives and the [text walkthrough](../usage.md#walkthrough) current. Check video playback in the rendered README rather than assuming an embed works.
