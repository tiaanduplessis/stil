# Security

## Report privately

Email [tiaanduplessis@hotmail.com](mailto:tiaanduplessis@hotmail.com) with the subject **Stil security report**. Do not include vulnerability details in an ordinary GitHub issue.

Include the affected version or source commit, Android version, steps to reproduce, expected impact, and any conditions such as work/private profiles. Share only the data needed to demonstrate the problem; do not send passwords, tokens, personal app data, or unrelated device logs.

Reports are handled by the maintainer as availability permits. There is no guaranteed response or fix timeline. Coordinate disclosure with the maintainer so a report can be investigated before sensitive details become public.

## Supported versions

Stil has no published APK release yet. Report issues against the current primary branch and include the exact commit. Supported released versions will be documented when releases exist.

## Reporting availability

The email address above is the reporting route while the repository is private. GitHub's private vulnerability-reporting feature has not been advertised as active. Recheck that feature and the monitored contact before any public release.
