# Stil

A proposed minimal Android launcher: a few essential apps, a clear way to find the rest, and an optional pause before distractions.

This workspace contains research and an interactive HTML design prototype. It does not contain an Android app yet.

- Open `mockups/index.html` directly in a browser. No installation, server, or internet connection is required.
- Read `docs/research.md` for the recommendation, competing products, Android constraints, and sources.
- Read `docs/design.md` for the visual direction and prototype review guide.

The prototype includes home, app search, an optional launch pause, settings, home customization, setup, font presets, and daily wallpaper controls. App launches and Android's default-home chooser are explicitly simulated. Preferences are saved in browser storage when available; Reset demo clears only Stil's prototype preferences.

Created 25 October 2026 in a new directory. There was no existing repository, remote, or primary branch to update. No Git repository has been initialized.

Wallpaper previews use local photos in `mockups/assets`. Keep this directory alongside the HTML file. Native wallpaper downloads and background scheduling are not implemented.
